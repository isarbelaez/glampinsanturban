# Template Astro para Producción

> **⚠️ IMPORTANTE:** Antes de usar este template, ejecuta `pnpm rename` para personalizar todos los nombres genéricos.

## Stack

- **Astro 6** — Framework web de alto rendimiento
- **React** — Componentes interactivos (client-side islands)
- **Tailwind CSS v4** — Estilos utilitarios
- **MDX** — Markdown enriquecido con componentes React
- **@astrojs/sitemap** — Sitemap automático para SEO
- **GitHub Actions** — Deploy automático a GitHub Pages

## Inicio Rápido

```bash
# 1. Clona el template
git clone https://github.com/GENERIC_USERNAME/GENERIC_REPO_NAME.git mi-proyecto
cd mi-proyecto

# 2. Instala dependencias
pnpm install

# 3. Personaliza con tu nombre de proyecto
pnpm rename

# 4. Inicia el servidor de desarrollo
pnpm dev
```

## Comandos Disponibles

| Comando             | Descripción                                |
| ------------------- | ------------------------------------------ |
| `pnpm dev`          | Servidor local en `http://localhost:4321`  |
| `pnpm build`        | Build de producción en `./dist/`           |
| `pnpm preview`      | Preview del build de producción            |
| `pnpm lint`         | Ejecutar ESLint                            |
| `pnpm lint:fix`     | Corregir errores de ESLint automáticamente |
| `pnpm format`       | Formatear con Prettier                     |
| `pnpm format:check` | Verificar formato sin modificar            |
| `pnpm rename`       | Script interactivo de renombrado           |
