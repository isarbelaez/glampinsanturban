# Mi Primer Post

Bienvenido a **glampinglean**. Este es un post de ejemplo usando MDX.

## ¿Qué es MDX?

MDX te permite usar componentes de React dentro de tu Markdown:

```tsx
// Puedes importar y usar componentes React aquí
import MyComponent from '../components/MyComponent.tsx';
<MyComponent />;
```

## Características del Template

- ✅ Astro 6 con Content Collections
- ✅ React para componentes interactivos
- ✅ Tailwind CSS v4 para estilos
- ✅ MDX para contenido enriquecido
- ✅ Sitemap automático para SEO
- ✅ Deploy automático a GitHub Pages
- ✅ ESLint + Prettier + Husky configurados

## Próximos Pasos

1. Ejecuta `pnpm rename` para personalizar el template con tu nombre de proyecto
2. Edita `astro.config.mjs` con tu URL de GitHub Pages
3. Crea tu propio contenido en `src/content/blog/`
4. Haz push a `main` para desplegar automáticamente

¡Buena suerte con tu proyecto! 🚀
